## 二、正文（可直接复制）

单位配的银河麒麟电脑，软件装不上、打印机不认、Windows 老软件没替代？—— 我接麒麟系统上的软件定制与适配。

【能做什么】
1. 桌面软件定制：Qt / Python 开发，原生跑在麒麟桌面版，界面按你的业务流程来
2. 外设与硬件对接：打印机、扫码枪、读卡器、串口/网口设备、仪器数据采集
3. Windows 软件迁移：老软件重做一版，或给可行替代方案，历史数据继续能用
4. 自动化小工具：Excel 批量处理、文件归档、定时任务、报表自动生成
5. 内网系统对接：OA / 业务系统 / 数据库取数、大屏展示、批量导入导出
6. 部署与培训：装包、配环境、写使用说明，教到你同事自己会用

【支持环境】
· 系统：银河麒麟桌面版 V10（SP1/SP2）、银河麒麟服务器版；统信 UOS 也能做
· 芯片：飞腾、鲲鹏、龙芯、海光、兆芯，x86 平台同样可做
· 其他：Ubuntu / Debian 系 Linux 也接，版本不同先评估

【怎么交付】
沟通需求 → 方案 + 报价 → 开发联调 → 麒麟真机验证 → 交付源码/安装包 + 使用说明 → 后续答疑
· 源码或安装包（含依赖）一并给，方便你单位后续维护
· 先出能用的版本，再按需迭代，不用一次压大预算
· 做不了的会直说，不做"拍下再想想"的单

【下单前请准备好】
1. 系统版本（设置 - 关于系统，截图最快）
2. 要装 / 要做的软件，或者想实现的功能
3. 现在卡在哪一步、报什么错（截图、录屏最好）
4. 是否内网、是否涉密，以及预算和时间要求

【关于价格】
按功能复杂度和工时评估，私聊说清需求后给一口价，不玩"先拍再加工"。需求越清楚，报价越快越准。
