## 二、正文（可直接复制）

国产化麒麟电脑，软件装不上、打印机不认、Windows 老软件没替代？—— 我接麒麟系统上的软件定制与适配。

【能做什么】
1. 桌面软件定制：Qt / Python 开发，原生跑在麒麟桌面版，界面按你的业务流程来
2. 外设与硬件对接：打印机、扫码枪、读卡器、串口/网口设备、仪器数据采集
3. Windows 软件迁移：用惯了的 Windows 软件重做一版，或给可行替代方案，用法尽量照旧
4. 自动化小工具：Excel 批量处理、文件归档、定时任务、报表自动生成
5. 打印模板与套打：发票、单据、条码标签按毫米排版，打印不跑偏
6. 数据看板与大屏：办公数据做成看板，浏览器打开就能看

【支持环境】
· 系统：银河麒麟桌面版 V10（SP1/SP2）、银河麒麟服务器版；统信 UOS 也能做
· 其他：Ubuntu / Debian 系 Linux 也接，版本不同先评估

【怎么交付】
沟通需求 → 方案 + 报价 → 开发联调 → 麒麟真机验证 → 交付安装包 + 使用说明
· 安装包（含依赖）和使用说明一起给
· 做不了的会直说，不做"拍下再想想"的单

【下单前请准备好】
1. 系统版本（设置 - 关于系统，截图最快）
2. 要装 / 要做的软件，或者想实现的功能
3. 现在卡在哪一步、报什么错（截图、录屏最好）
4. 是否内网、是否涉密，以及预算和时间要求

【关于价格】
按功能复杂度和工时评估，私聊说清需求后给一口价，不玩"先拍再加工"。需求越清楚，报价越快越准。

【适合谁】
自己在用国产电脑被软件卡住的个人用户、小企业主、行政财务、学校老师。

## 三、常见问法速回（存快捷短语）

- "能装 XX 软件吗？" → 发我软件名 + 系统版本截图，我确认有没有麒麟版或替代方案，能做的直接报价。
- "多少钱？" → 看功能量和要不要对接设备，简单小工具和整套系统差别很大，你说下要做什么，我给一口价。
- "能保证跑通吗？" → 我在麒麟真机上验证过才交付；评估下来做不了的，我会提前说，不接这种单。
- "要多久？" → 小工具几天，带界面和对接的一般按周算，确认需求后给你明确时间点。
