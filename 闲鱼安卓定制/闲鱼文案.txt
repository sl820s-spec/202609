▍先说重点
安卓 App 定制开发，从一句需求，做到能装到手机上真的能用。
课程设计 / 毕业设计 / 小工具 / 工具类 App 都能接。

▍能做什么
· 登录注册、页面导航、列表详情
· 本地数据库、增删改查、离线可用
· 图表统计、数据看板
· 接口对接（后端 API、天气、地图、登录鉴权）
· 拍照上传、扫码识别、文件读写
· 蓝牙 / 串口设备连接、实时数据
· App + Web 后台整套打通

▍交付什么
✓ 完整源码：Android Studio 工程，可直接导入编译，不是反编译产物
✓ 可运行 APK：装机即用，附安装说明
✓ 需求文档：功能清单、页面说明、数据结构，写报告直接能用
✓ 使用说明：怎么跑、怎么改、常见报错怎么处理
✓ 远程陪跑：帮你把环境跑通，依赖版本我负责
✓ 答辩要点：每个模块怎么实现、为什么这么设计，讲得明白

▍价格参考（按功能报价，最终以沟通后的清单为准）
¥199 起｜单页面小工具、课程 Demo，3–5 天

加急 / 二次开发 / 长期维护，价格另议。

▍怎么合作
1. 私信说需求：有文档发文档，没文档就说想法 + 一个参考 App
2. 我给功能清单、固定价和工期，确认后再开工
3. 分阶段看进度：界面 → 功能 → 打包，每个节点给你截图或录屏
4. 验收通过 → 交源码和文档 → 平台确认收货

▍私信格式
